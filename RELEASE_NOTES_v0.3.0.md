# Codex Agent v0.3.0

- Answer clarification questions directly in a Codex Hub task card. The agent continues in the same conversation after you reply.
- Waiting for an answer does not start model work or consume inference tokens. Pending questions survive an agent restart.
- Keep completion reports short, without progress commentary.
- The board now removes stale projects, merges duplicate project entries without losing tasks, and supports manual removal with Undo.

## Windows installation

Download **Codex-Agent-Setup-x64.exe** and run it to install or update. Node.js is included. Codex is not bundled: the agent uses your existing Codex installation and account.
