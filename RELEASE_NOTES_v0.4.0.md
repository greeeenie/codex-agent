# Codex Agent v0.4.0

- Choose a model and reasoning effort for each board task from your installed Codex model catalog.
- Attach files and images before creating a task. Files are saved with the task, downloaded into its project, and included in the agent input; images are also passed as image inputs.
- Use the new compact composer with file attachment, model selection, browser dictation, and a send button. Voice availability depends on browser speech recognition support.
- Preserve task titles and project assignments across restored conversations.

Download **Codex-Agent-Setup-x64.exe** to install or update. Node.js is included; your existing Codex installation and account are used.
