# Codex Agent

Локальный агент для [Codex Hub](https://agent-board-stepan.readymars.chatgpt.site). Берёт задачи с доски и выполняет их в локальных проектах через официальный Codex app-server.

## Windows

1. Скачайте codex-agent-windows.zip из [последнего релиза](https://github.com/greeeenie/codex-agent/releases/latest).
2. Распакуйте в отдельную папку и запустите Start.cmd. Нужен Node.js 22+ ([LTS](https://nodejs.org/)). Если Codex CLI отсутствует, скрипт установит официальный пакет @openai/codex через npm.
3. Подтвердите привязку компьютера в открывшейся странице Codex Hub.
4. При необходимости войдите в Codex в официальном браузерном окне.
5. Оставьте агент запущенным и добавляйте задачи на доске. Остановка: Ctrl+C.

Проверка очереди не вызывает модель. Модель работает только над задачами. Результат и настоящие скриншоты возвращаются на ревью. Дополнительные разрешения не выдаются автоматически.

## Проекты

Агент обнаруживает локальные проекты Codex по метаданным .codex/.codex-global-state.json. Внутренний формат может измениться. Для ручной настройки создайте .sites-runtime/runner.json по runner/projects.example.json. В конфигурацию не нужно добавлять секреты. Удалённые проекты пока не поддерживаются.

## Доступ

Сайт остаётся приватным. Токен привязки передаётся через локальный HTTP callback с проверкой Origin и случайного state; в URL и командную строку секрет не попадает. Windows хранит его зашифрованным через DPAPI для текущего пользователя в %LOCALAPPDATA%/CodexAgent/connection.json. Codex сам управляет входом в ChatGPT; агент не читает auth.json. На macOS/Linux запустите node runner/start.mjs; подключение сайта потребуется повторять при запуске.

Для удаления локальной привязки остановите агент и удалите connection.json. Для полного отзыва сервисного доступа отзовите токен на стороне Sites. Не публикуйте свой токен в issues или логах.

## Разработка

node --test runner/engine.test.mjs

Никаких npm-зависимостей у самого агента нет. Проект использует установленный официальный Codex CLI. Запуски идут в sandbox workspace-write; если нужно дополнительное разрешение или ответ, задача останавливается на ревью. Восстановление продолжает сохранённый контекст, но не откатывает изменения файлов.
