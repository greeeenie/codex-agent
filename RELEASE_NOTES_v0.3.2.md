# Codex Agent v0.3.2

- Automatically attach new task conversations to the selected Codex desktop project.
- Retain the project assignment when restoring tasks or resuming a pending question.
- Resolve desktop and app-server project identities using the saved mapping and verified project directory. Ambiguous or missing projects return the task to Backlog without starting model work.

Download **Codex-Agent-Setup-x64.exe** to install or update. Your existing Codex installation and account are used.
